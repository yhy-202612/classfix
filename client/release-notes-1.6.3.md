# ClassFix 1.6.3 更新

## 新增：放映出问题时，自动给一份「分层诊断」

课堂上视频一黑屏，过去只能看到一句「播放异常」。现在 ClassFix 会把能证明问题的几路证据一起收集，输出一份分层结论：

- PPTX 与媒体：这个课件里的视频是嵌入还是外链，引用是否还在；
- 默认输出音量与静音状态：故障当刻系统是不是被静音、音量是不是 0；
- 放映状态：出问题的是第几页、哪一个课件；
- PowerPoint 原始报错：直接从 PowerPoint 自己的对话框里读出报错原文；
- PowerPoint 放映接口：读取播放器状态时 COM 接口有没有返回错误；
- Windows 事件日志：故障前后 10 秒内，PowerPoint 进程有没有崩溃、无响应或被拉黑；
- ETW 短时追踪：在故障窗口内抓一小段进程过滤的追踪样本，只保留与 PowerPoint 有关的记录。

每条证据都标注了「已确认 / 未取得」，不会拿猜测当结论。

## 新增：提示框里能直接看到 PowerPoint 的报错原文

课件放不出来时，右下角提示会写清是第几页、检测依据是什么，并把 PowerPoint 弹出的报错原文附在后面。读不到时会明说「未读取到」，不会编一句原因。

## 新增：内存紧张时提醒，并可一键优化

放映期间如果系统内存吃紧，右下角提示会给出当前内存占用率，可一键执行内存优化（全局工作集、文件缓存、已修改页、待机页、低优先级待机页、注册表整理、物理页合并），也可「1 小时内不再提醒」或直接打开任务管理器。优化在短命的独立进程里完成，跑完即退。

## 修复：多个提示不再互相遮挡

音量弹窗与扫描告警同时出现时，原来会互相盖掉。现在按屏幕位置排队展示、动画不重叠，音量滑条只在你拖完滑块后才自动收起。

## 修复：打开验证只关闭自己的那份副本

打开验证结束时，只关闭它自己打开的那份临时副本。PowerPoint 里其它正在用的课件、以及你设置的提示偏好都保持原样，不会被一起关掉。

## 兼容性

本地记录、设置、登录态仍保存在 `%LOCALAPPDATA%\ClassFix`，覆盖升级不丢数据。1.5.x 可以在线升级到 1.6.3；不能联网的机器把发布包拷过去，用「从文件更新…」。
